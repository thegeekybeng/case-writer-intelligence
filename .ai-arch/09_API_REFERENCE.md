# API Reference

- `POST /api/ai/login`: Authenticates admin using `ADMIN_USER` and `ADMIN_PASS`.
- `POST /api/ai/chat`: Chat interaction with PII masking.
- `POST /api/ai/analyze`: Case note analysis.
- `POST /api/ai/categorize`: Categorizes conversation.
- `POST /api/ai/letter`: Generates letters.
- `POST /api/v1/chat/completions`: Streaming inference endpoint for Causality Engine.
